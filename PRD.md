# PRD.md

## Figma Plugin PRD: AI-Powered Code Generator

---

### Overview

#### Product Description

This Figma plugin enables users to generate and execute custom Figma Plugin API functions based on natural language prompts. The plugin has no custom UI; it leverages Figma's quick actions menu for prompt input. The user's prompt is sent to a Large Language Model (LLM) via the Vercel AI SDK (using the OpenRouter connector). The LLM generates a single, executable JavaScript function that interacts with the Figma Plugin API. This function is then executed in the plugin's environment using `eval` for immediate effect. The goal is to automate simple Figma tasks (e.g., "Create a red rectangle in the center of the canvas") without manual coding.

#### Target Audience

- Figma users (designers, developers) who want quick automation without deep coding knowledge.
- Plugin developers prototyping ideas rapidly.

#### Key Benefits

- Simplifies Figma automation by translating natural language to executable code.
- No UI overhead; runs directly from quick actions.
- Immediate execution with feedback via console logs.

#### Assumptions and Constraints

- Plugin runs in Figma's editor (Design, FigJam, or Slides compatible where possible).
- Relies on Vercel AI SDK for LLM integration; requires an OpenRouter API key.
- `eval` is used for execution; assumes Figma's sandbox allows it (verified via testing).
- LLM output must be strictly controlled to return only valid JS code to avoid eval errors.
- No persistent state; each run is independent.
- Handles asynchronous Figma API calls (e.g., loading fonts) appropriately in generated code.

---

### Requirements

#### Functional Requirements

1. **Plugin Initiation**

   - The plugin launches without a UI (uses `figma.showUI` with hidden or no UI if needed).
   - It opens Figma's quick actions menu, prompting the user for a single text input: the natural language prompt (e.g., "Duplicate the selected layer and rotate it 45 degrees").

2. **Prompt Processing**

   - Capture the user's prompt via Figma's plugin parameters.
   - Send the prompt to an LLM using Vercel AI SDK with OpenRouter connector.
   - LLM model: Use a capable model like `openai/gpt-4o` via OpenRouter for code generation accuracy.

3. **LLM Code Generation**

   - The LLM is given a comprehensive system prompt (detailed below) to generate a single JavaScript function.
   - The function must:
     - Use Figma Plugin API methods (e.g., `figma.createRectangle()`, `figma.currentPage.selection`).
     - Be self-contained, executable, and error-free.
     - Include `console.log` statements for feedback (e.g., success, failure, or status).
     - Handle asynchronous operations (e.g., `await figma.loadFontAsync()`).
   - LLM output must be **only the function code** (no explanations, wrappers, or extra text) to ensure safe eval.

4. **Code Execution**

   - Receive the generated function as a string.
   - Wrap it in a safe eval context (e.g., `eval((function() { ${code} })())`) to execute it immediately.
   - Log execution results to Figma's console for user visibility.

5. **Error Handling**

   - If LLM generation fails or code is invalid, log an error and notify the user (e.g., via `figma.notify`).
   - Catch eval errors and provide friendly feedback.

6. **Feedback and Logging**
   - Generated code includes logs for key events (e.g., "Function executed successfully", "Error: No selection found").
   - Plugin logs overall status (e.g., "Code generated and executed").

#### Non-Functional Requirements

- **Performance**: LLM calls should be optimized for speed; use efficient models. Total execution < 5 seconds for simple prompts.
- **Security**:
  - Only execute code generated by trusted LLM.
  - Sanitize/validate generated code before eval (e.g., check for forbidden keywords like `fetch` to prevent external calls).
  - Use OpenRouter's secure API.
- **Reliability**: LLM system prompt must enforce strict output format to minimize invalid code.
- **Accessibility**: Ensure logs are console-based; no visual UI required.
- **Compatibility**: Works in Figma Design/FigJam; test in Dev Mode if needed.
- **Dependencies**:
  - Vercel AI SDK for LLM integration.
  - OpenRouter connector for model access.
  - Figma Plugin API (latest version).

### Technical Design

#### Architecture

- **Plugin Structure:**

  - `manifest.json`: Define plugin with parameters for prompt input. Set `"ui": false` or minimal hidden UI.
  - Main script (`code.ts`): Handle parameter input, LLM call, code eval.

- **LLM Integration:**
  - Use Vercel AI SDK: `import { openrouter } from '@ai-sdk/openrouter';`
  - Generate text: `generateText({ model: openrouter('openai/gpt-4o'), system: SYSTEM_PROMPT, prompt: userPrompt })`
  - Extract raw function string from response.

#### System Prompt for LLM

To optimize generation, the system prompt must:

- Include key excerpts from Figma Plugin API docs.
- Instruct strict output format: Only the function code.
- Emphasize error-free, executable code with logs.

**Sample System Prompt:**

```
You are an expert Figma Plugin API coder. Your task is to generate a SINGLE JavaScript function based on the user's prompt. The function must:

- Be named 'main' and take no arguments (e.g., function main() { ... }).
- Use only the Figma Plugin API (figma object) and standard JS. No external libraries.
- Be fully executable in Figma's plugin environment: Handle async operations with await (e.g., await figma.loadFontAsync({ family: "Roboto", style: "Regular" })).
- Include console.log for feedback: e.g., console.log("Success: Rectangle created"); or console.log("Error: No selection found");
- Be error-free: Check for selections, handle cases like no current page, etc.
- Close the plugin after execution with figma.closePlugin() if appropriate.
- Output ONLY the function code. No explanations, no extra text, no wrappers.

Key Figma Plugin API Docs:
- Access current page: figma.currentPage
- Selection: figma.currentPage.selection
- Create nodes: figma.createRectangle(), figma.createText(), etc.
- Append to page: figma.currentPage.appendChild(node)
- Async font loading: await figma.loadFontAsync({ family: "Inter", style: "Regular" })
- Notifications: figma.notify("Message")
- Full docs reference: [Include summarized API nodes, properties, methods from provided docs, e.g., DocumentNode, PageNode, createFrame, setRelaunchData, etc.]

User prompt: [USER_PROMPT]
Generate the function to fulfill this prompt using Figma API.
```

#### Execution Flow

1. User runs plugin via quick actions.
2. Input prompt via parameters.
3. Plugin sends prompt + system prompt to LLM.
4. Receive function string.
5. Validate (e.g., check if it starts with 'function main(').
6. Eval and execute.
7. Log results.

#### Potential Risks and Mitigations

- **Invalid LLM Output**: System prompt enforces format; fallback to error message if malformed.
- **Eval Security**: Limit to Figma API calls; reject code with network requests.
- **API Limits**: Handle rate limits in OpenRouter; inform user on failures.
- **Async Handling**: Ensure generated code uses await for Figma async methods.
