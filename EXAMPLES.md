# FigPal Usage Examples

Here are some example prompts you can try with FigPal to get started:

## Basic Shape Creation

### Rectangles and Squares

- "Create a red rectangle"
- "Make a blue square in the center of the canvas"
- "Create a rectangle that is 200px wide and 100px tall"

### Circles and Ellipses

- "Create a green circle"
- "Make a yellow ellipse"
- "Create a circle with a radius of 50px"

### Complex Shapes

- "Create a star shape"
- "Make a polygon with 6 sides"
- "Create a triangle"

## Working with Text

### Basic Text

- "Create text that says 'Hello World'"
- "Make a text element with the content 'Welcome' in Arial font"
- "Create a heading that says 'My Design'"

### Styled Text

- "Create large bold text that says 'Title'"
- "Make italic text that says 'Subtitle'"
- "Create text in size 24 that says 'Big Text'"

## Working with Selections

### Modifying Selected Objects

- "Change the fill color of selected objects to red"
- "Make the selected object 50% transparent"
- "Rotate the selected object by 45 degrees"
- "Duplicate the selected object"

### Grouping and Organization

- "Group all selected objects"
- "Ungroup the selected group"
- "Align selected objects to the center"

## Layout and Positioning

### Positioning

- "Move the selected object to the center of the canvas"
- "Position the selected object at x:100, y:50"
- "Move the selected object 50px to the right"

### Sizing

- "Resize the selected object to 200x200 pixels"
- "Make the selected object twice as big"
- "Set the width of the selected object to 300px"

## Advanced Operations

### Frames and Components

- "Create a frame that is 375x812 pixels" (iPhone frame size)
- "Make a component from the selected object"
- "Create an instance of the selected component"

### Effects and Styling

- "Add a drop shadow to the selected object"
- "Make the selected object have a border"
- "Add a blur effect to the selected object"

## Tips for Better Results

### Be Specific

❌ "Make it bigger"
✅ "Resize the selected object to 300x200 pixels"

### Use Clear Colors

❌ "Make it a nice color"
✅ "Change the fill color to blue" or "Set the color to #FF0000"

### Specify Measurements

❌ "Move it a bit"
✅ "Move the selected object 20px to the right"

### Include Context

❌ "Duplicate it"
✅ "Duplicate the selected layer and move it 50px down"

## Common Operations

### Daily Design Tasks

- "Create a button with rounded corners"
- "Make a card layout with padding"
- "Create a navigation bar"
- "Set up a grid of 3x3 squares"

### Content Creation

- "Create a title and subtitle for a landing page"
- "Make a logo placeholder that is 100x100"
- "Create a profile picture placeholder"

### Organization

- "Create folders for organizing layers"
- "Rename the selected layer to 'Header'"
- "Lock the selected objects"

## Troubleshooting Common Issues

### If the AI doesn't understand:

- Be more specific about what you want
- Break complex requests into smaller steps
- Use Figma terminology (layer, frame, component, etc.)

### If execution fails:

- Make sure you have objects selected when required
- Check that fonts are available if working with text
- Verify the operation is possible in current context

Try these examples to get familiar with FigPal's capabilities!
